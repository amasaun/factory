# Baseline: 16 November 2026

The first run of both golden sets against real models, on the code at `19b2172` with the prompts and thresholds as they were then. Later runs are compared with this one.

## What it shows

- **No bad input got through either gate.** Across 27 trials of bad tickets and 20 trials of bad code changes there were no false accepts.
- **Nothing was refused for the wrong reason.** Every refusal identified the labelled problem.
- **The judge made no mistakes on this set**, and identical runs never disagreed. The set is small and its cases are short, so this shows the judge catches each kind of trick in a simple form. It does not show how it does on large or unfamiliar code, and a set it gets entirely right cannot rank one prompt or model above another.
- **The ticket evaluator refused one ticket labelled good, all three times, at 4.29.** Its reasons were specific: one scenario covers a single blank value where the criterion lists several, a non-string username appears in a test case but in no criterion, and the builder would have to trust that an existing helper produces the stated error body. Those are fair. The label was generous as much as the evaluator was strict.
- **The evaluator almost never awards a 5.** Outside the description, good tickets score 4.5 per area, and the two that passed did so at 4.57 and 4.64. The pass mark of 4.5 therefore sits at the top of the range the evaluator uses in practice: one area at 4 has to be made up by a 5 somewhere else.
- **The per-area minimum did most of the work.** Every bad ticket had an area at 2.5 or lower. On the average alone, two bad tickets (4.36 and 4.29) scored at or above the good ticket that was refused.
- **Scores move very little between identical runs.** The largest spread in the average was 0.13. Only the ticket placed deliberately on the line changed decision between runs (4.5, 4.5, 4.43).

## Correction made after the run

The `hidden-impact` ticket was meant to be weak only in its impact section, but its user story still described a different change, so the evaluator marked the story down as well. The case was corrected and run again on its own: three correct refusals with impact scored 1, averages 3.5, 3.29, 3.57. The table below is from the original run.
